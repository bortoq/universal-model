# Assoc — спецификация ассоциативной адресации (standalone, без согласования с vm1)

Статус: черновик v0.1, 2026-08-24. Согласование `pos<->value` — отдельно.

## 1. Задача

Адресация по значению без прямого доступа к битам. Только перенумерация:

```
encode: V -> K, |K| < |V|
decode: K -> окрестность {V'}
```

`V` — битовая строка значения (окно из `S0=n·2ⁿ`), `K` — ключ-адрес. Сжатие обеспечивает экспоненциальную экономию, пирамида `S0->S1->...->1 ключ` будет позже, сейчас — один уровень `V->K`.

## 2. Интерфейс

```python
def encode(value: bytes) -> bytes:  # |V| бит -> |K| бит
def decode(key: bytes) -> list[bytes]: # K -> top-k ближайших V' (окрестность)
def distance(a: bytes, b: bytes) -> int # Hamming между V
```

Параметры по умолчанию (переопределяются):
- `|V| = 256 бит (32 байта)`
- `|K| = 32 бит (4 байта)` — сжатие 8x, `|K|<|V|`
- `|V|/|K| = 8` => `t = ceil(log_8(n·2ⁿ/|K|))` для будущей пирамиды

Ограничение: кодбук один, переиспользуемый (tied-VQ, низкая энтропия, 10-17 переиспользований в пирамиде).

## 3. Метрики

- `recall@k`: доля случаев когда `decode(encode(V))` содержит исходное `V` в топ-k
- `neighbor_precision@k`: доля возвращенных `V'` с `Hamming(V,V') <= threshold`
- `compression`: `|V|/|K|`
- `codebook_usage`: энтропия использования кодов (не должна коллапсировать)

Успех v0.1: `recall@10 >= 0.9` на синтетике `|V|=256`, `random V` + `noisy copies`.

## 4. Датасет

Окна `V` из:
1. синтетика: `random 256-bit` + `noisy copies` (flip 1-5 бит) — окрестность по Hamming
2. позже: дампы `vm1` `S0` (позиционные значения)

Формат: `npz` с массивами `V: [N, 32] uint8`, `V_noisy: [N, 32]`.

## 5. Модель v0.1

Baseline без трансформера для проверки интерфейса:
- `encode`: `V (256 бит) -> hash -> K (32 бит)` через обучаемый `MLP + VQ` (tied)
- `decode`: `K -> V'` через `MLP` + поиск по кодбуку (Hopfield-like)

v0.2: `TransformerEncoder (2 layers, d=128) -> VQ (codebook 1024 x 32) -> TransformerDecoder`

## 6. Что НЕ делаем сейчас

- Согласование `pos->value->key->pos'` с `vm1` (отдельный репо/ветка)
- Пирамидальное сжатие `S0->S1->...`
- Аппаратная оценка
