# Ассоциативная адресация — временная эмуляция

Статус: в разработке, ~10 прототипов, сложнее позиционной.

Временная замена — трансформер `encode(value)->key` (`|K|<|V|`) и `decode(key)->окрестность`. Пирамидальное сжатие `S0=n·2ⁿ -> ... -> 1 ключ`, `t=log`, см. §18 статьи.

4. встройка вместо ассоциативного блока с проверкой `pos->value->key->value'->pos'`

Подробная спецификация будет в этом каталоге. Связанный код — `vm1/` (позиционная) + будущий `assoc/transformer/`.
