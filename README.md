# Универсальная модель

## Примечание

Из-за бурного развития ИИ и постоянного появления новых, плохо проверенных примеров и инструментов его использования возникла необходимость досрочной публикации статьи об универсальной модели.

Универсальная модель описывает концепцию нового понимания достоверности, вводя доказательство существования взамен доказательства истины. Для этого предлагается тавтологический метод вместо аксиоматического. Работа над статьей ведётся с осени 2014 года. К статье прилагается код эмуляции механизмов модели. Часть механизмов статьи не полностью реализована. Статья состоит из понятий, введённых определениями, данными как механизмы или как уже введённые понятия. Часть статьи, дающая понятия, не окончена. Статья представляет собой набросок, а не полноценный документ.

## Краткое описание универсальной модели
УМ задает условия в которых будут выполняться вычисления доказательств имеющих достоверность физической реальности (замена тезиса тьюринга). для этого вводится единственное требование к реальности - быть собой. "быть собой" проверяется соответствием результата измерения результату вычисления с помощью взаимного предсказания: оба значения должны быть равны друг другу одновреенно. проверка выполняется в канале существования которому соответствует проверка утверждения тавтологической логики.
аксиоматика логики состоит из аксиомы равенства. равенство проверяется в канале существования. в результате проверки в собственном пространстве вычислительной системы появляется доказательство существования. 
вс доказывает свое существования доказывая существование в смежном адресном пространстве утверждений. утверждения в смежном пространстве представлены измеряемыми значениями, а в собственном пространстве - вычисляемыми.
