# Универсальная модель

## Примечание

Из-за бурного развития ИИ и постоянного появления новых, плохо проверенных примеров и инструментов его использования возникла необходимость досрочной публикации статьи об универсальной модели. в статье предпринимается попытка внести ясность в понятие интеллект и понятия необходимые для его определения.

Универсальная модель описывает концепцию нового понимания достоверности, вводя доказательство существования взамен доказательства истины. Для этого предлагается тавтологический метод вместо аксиоматического. Работа над статьей ведётся с осени 2014 года. К статье прилагается код эмуляции механизмов модели. Часть механизмов статьи не полностью реализована. Статья представляет собой набросок, а не полноценный документ.

## Краткое описание универсальной модели
УМ задает условия в которых будут выполняться вычисления доказательств имеющих достоверность физической реальности (замена тезиса тьюринга). для этого вводится единственное требование к реальности - быть собой. "быть собой" проверяется соответствием результата измерения результату вычисления с помощью взаимного предсказания: оба значения должны быть равны друг другу одновреенно. проверка выполняется в канале существования которому соответствует проверка утверждения тавтологической логики.

аксиоматика логики состоит из аксиомы равенства. равенство проверяется в канале существования. в результате проверки в собственном пространстве вычислительной системы появляется доказательство существования. 

вс доказывает свое существования доказывая существование в смежном адресном пространстве утверждений. утверждения в смежном пространстве представлены измеряемыми значениями, а в собственном пространстве - вычисляемыми.

понятия определяются через другие понятия. первое понятие т.к. еще нет других понятий обозначает (обозначение - действие эмулируемое наблюдением) себя. понятие - это значение некоторой логики. определение - это действие адресующее значение в наблюдаемом адресном пространстве.

понятия вводятся через другие понятия. чтобы ввести первое понятие приходится использовать определение. в качестве определения являющегося понятием используется тавтология - понятие определяемое собой. определения даются как механизмы или как уже введённые понятия. ## Тавтология
тавтология - является собой. тавтология осуществляет действие (являться) ссылкой на себя, т.е. адресует себя и т.о. является адресным пространством.

## Понятие
понятие - это значение логики. понятия определяются через другие понятия. первое понятие т.к. еще нет других понятий обозначает (обозначение - действие эмулируемое наблюдением) себя.

## Определение
определение - это действие адресующее понятие в наблюдаемом адресном пространстве. могут адресоваться понятия не только из собственного адресного пространства логики он и из ее смежного пространства.

## Доказательство
измерение достоверности. совпадение вычисленного значения (утверждения: по такому адресу существует такое значение) с измеренным. выполняется с точностью до существования вс осуществляющей доказательство. если удается доказать существование измеряемого пространства то вс достаточно мощна чтобы быть его определением и содержать его понятие. 
подтверждение существования. может быть предоставлено тавтологически (доступно при адресации 1-го порядка) или вычислительно (без доступа к адресации 2-го порядка, но с эмуляцией адресации 2-го порядка)
(утверждение в унарной вс тавтологической логики является собственным доказательством) достоверность доказательства обеспечивается тем что его нельзя опровергнуть. если доказательство не удается опровергнуть никакими утверждениями умещающимися в пространство экспоненциального размера по сравнению с размером проверяемым доказательством, то доказательство считается достоверным. мера достоверности не истина, а существование

## Адресация
сопоставление утверждения логики представлению пространства, т.е. нумерация утверждений числами арифметики соответствующей пространству. т.е. адресация - это язык.

## Адрес
путь адресации. путь в позиционной адресации является частично (т.к. сортировка может иметь слои перестановки которые можно переставлять) упорядоченным набором транспозиций. путь в ассоциативной адресации является упорядоченным набором упорядоченных сортировок.

## Адресное пространство
адресное пространство гарантирует доступ к значениям которые содержит.

адресное пространство решает одну задачу: адресацию. если решается адресация действия, то это позиционная адресация. если решается адресация значения, то это ассоциативная адресация.

## Позиционная адресация
позиционнный адрес - адресуются позиции (значения хранимые в позициях изолированы)

## Ассоциативная адресация
ассоциативный адрес - перенумероваются изолируемые значения, дальше вся работа осуществляется только с представлениями из нумерации. в качестве ключа берется представление номера значения в данной позиции. (перенумеровывать надо чтобы с одной стороны иметь возможность адресоваться по значениям, но с другой не должны иметь доступа к значениям).
