# Протокол каналов

## Назначение

Этот документ описывает текущий дизайн каналов адресного пространства.

Протокол каналов является частью определения пространства, потому что через него в пространство возвращается результат внешнего копирования.

## Канальная инструкция

Канал задаётся своей инструкцией в `PROCESSOR`.

Номер канальной инструкции в `PROCESSOR` является номером канала.

Для канальной инструкции:

- `n` задаёт число копируемых бит;
- один индекс используется как индекс позиции внутреннего буфера;
- другой индекс не участвует во внутреннем копировании и используется для возврата результата канальной операции.

## Результат внешнего копирования

Протокол обслуживания канала возвращает два значения:

1. число реально скопированных бит;
2. бит причины, если число реально скопированных бит меньше заказанного.

Значения бита причины:

- `0` — `EOF`;
- `1` — ошибка.

Число реально скопированных бит и бит причины возвращаются через индекс канальной инструкции, не участвующий во внутреннем копировании.

## Обнаружение каналов

Эмулятор размещает найденные им каналы в `PROCESSOR`.

Модель может определить доступные каналы, прочитав `PROCESSOR` до его перезаписи.
